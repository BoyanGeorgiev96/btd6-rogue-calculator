# Feedback and contributions

Rogue Lab is maintained by Boyan Georgiev. Report bugs, suggest features, or share evidence for calculation corrections through [GitHub Issues](https://github.com/BoyanGeorgiev96/btd6-rogue-calculator/issues). Please search existing issues before opening a new one.

External pull requests are currently not accepted. The maintainer handles implementation and reviews automated data-update PRs.

Use the bug report, calculation correction, or feature request form when opening an issue. For security vulnerabilities, follow the [security policy](.github/SECURITY.md) and report privately.

## Reporting a bug

Include:

- Steps to reproduce the problem, with expected and actual behavior.
- A shared build link or the relevant tower/hero, upgrades/level, artifacts, rarities, target, and conditions.
- Browser and device details for interface problems; screenshots can help.

Remove any personal information from links, screenshots, or exported files before posting.

## Calculation corrections and feature suggestions

For calculation corrections, include the game version and source fields, official notes, or reproducible measurements that support the expected result. Make clear what you observed and what you assumed. Reviewed data sources and known exclusions are documented in the [README](README.md#data-and-attribution); proposed changes follow the existing [data and rule review process](docs/artifact-rules.md).

For feature suggestions, describe the problem you want to solve and an example of how the feature would help. An issue does not guarantee implementation or a delivery date.
